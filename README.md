# Webmuic (本机自用聚合音乐播放器)

本机自用的现代 WebUI 音乐播放器，聚合**网易云音乐**与 **QQ 音乐**。所有服务默认仅绑定 `127.0.0.1`，平台 Cookie 仅由网关在本机安全持有，绝不下发至前端。

---

## 🪟 Windows 用户使用指南 (开箱即用)

Windows 用户只要电脑上安装了 **Node.js (LTS 18/20+)** 与 **npm**，无需手动安装 pnpm，即可一键启动！

### 方式 A：鼠标双击一键运行（推荐）

1. **首次运行 / 安装依赖**：
   - 双击根目录下的 **`install-windows.bat`**。
   - 脚本会自动检测 Node.js 与 npm 环境，通过 `npx pnpm` 自动装好所有模块，并自动打好 QQ 音乐兼容补丁。
2. **日常启动播放**：
   - 双击根目录下的 **`start-windows.bat`**。
   - 脚本将守护启动 4 个微服务并**自动在浏览器打开 `http://127.0.0.1:5173`**。
   - 在黑框控制台按 `Ctrl + C` 并输入 `Y` 即可安全终止全部后台服务（内置进程树清理，绝不残留端口占用）。

### 方式 B：终端命令行运行 (CMD / PowerShell)

```bash
# 1. 一键安装全部依赖并应用补丁 (自动通过 npx 支持)
npm run bootstrap

# 2. 一键启动并自动打开浏览器
npm run start:open
# 或者普通启动: npm start
```

## 🐧 Linux / macOS 开发与运行

### 1. 依赖安装

```bash
# 推荐使用 pnpm
pnpm install

# 或者使用跨平台一键向导 (自动处理 workspace、QQ 依赖与补丁)
node scripts/install-all.mjs
```

### 2. 启动服务

```bash
pnpm dev
# 或
node scripts/dev-all.mjs
```

启动后访问: `http://127.0.0.1:5173`

## 架构说明

```text
浏览器 WebUI: http://127.0.0.1:5173 (Vue 3 + Vite + Pinia)
      │
      ▼ (Vite /api 代理)
网关服务:   http://127.0.0.1:8787 (Express + TypeScript, 凭证隔离/统一契约/音频代理)
      ├── 网易云后端: http://127.0.0.1:3010 (NeteaseCloudMusicApi)
      └── QQ 音乐后端: http://127.0.0.1:3200 (Rain120/qq-music-api, 已自动打补丁)
```

## 功能特性

- 🎵 **双平台聚合搜索与播放**：支持网易云音乐与 QQ 音乐单曲、专辑、歌单解析与无缝试听。
- 📱 **扫码与凭证持久化**：网易云二维码扫码、QQ 扫码 / 微信扫码，凭证本机加密持有，无需重启服务。
- 📜 **滚动歌词与副歌定位**：支持毫秒级同步歌词滚动与逐句跳转；支持智能高潮/副歌定位标记（🔥 一键跳至副歌高潮）。
- 🎨 **自适应现代化 UI**：全自研纯净设计，无第三方庞大组件库负担，支持浅色/深色主题流畅切换。
- 🛡 **安全与孤儿进程防护**：跨平台（Win32 `taskkill /T /F`，POSIX 进程组杀戮）安全终止机制，防止端口被占用。
